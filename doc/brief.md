## Идея

Интернет сайт для обьявлений от пользователей. Простой, удобный, быстрый. Одни размещают обьявления с фото и деталями. Другие используют сайт для покупки или в получения в дар, с удобными фильтрами и интерфейсом. 

Помимо интерфейса, раздел с событиями, например, выставки, соревнования и прочее.

На двух языках, казахский и русский. 

Помимо продаж домшних животных, так же продажа скота. Возможность продажи опотом/табунами. 

Так же раздел с около животными обьявлениями: например, кормы, средства по уходу, услуги кинолога и прочее.

Для управления сайтом. Просто и удобный интерфейс для модерации и управления сайтом.

## Рекомендуемый стек

### Frontend

| Технология | Зачем |
|---|---|
| **Next.js 14** (App Router) | SEO из коробки через SSR/SSG — критично для объявлений |
| **Tailwind CSS** | Быстрая вёрстка, легко поддерживать |
| **shadcn/ui** | Готовые компоненты — не нужно изобретать UI |
| **next-intl** | i18n для казахского / русского, простая настройка |

### Backend & инфраструктура

| Технология | Зачем |
|---|---|
| **Supabase** | PostgreSQL + Auth + Storage + Realtime — всё в одном |
| **Vercel** | Деплой Next.js одной кнопкой, щедрый бесплатный тир |
| **Supabase Storage** | Фото объявлений, без лишних сервисов |
| **Cloudflare** | DNS + CDN + защита от DDoS + кэширование статики |

## Как это закрывает требования

| Требование | Решение |
|---|---|
| Объявления с фото | Supabase Storage + таблица `listings` |
| Фильтры и поиск | PostgreSQL full-text search или `pg_trgm` |
| Авторизация пользователей | Supabase Auth (email, Google, phone) |
| Два языка (kz / ru) | `next-intl` — два JSON-файла с переводами |
| События (выставки, соревнования) | Отдельная таблица `events` в той же БД |
| Продажа оптом / табунами | Поля `quantity`, `is_bulk` в таблице `listings` |
| Раздел около-животных услуг | Категории в той же структуре, отдельный `category_type` |
| Модерация и админка | Next.js `/admin` route + Supabase RLS политики |
| Скорость и защита | Cloudflare CDN кэширует статику, прячет origin IP |
| Фото объявлений быстро | Cloudflare кэширует Supabase Storage URL на edge |
